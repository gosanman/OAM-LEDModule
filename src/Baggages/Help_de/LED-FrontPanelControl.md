### Steuerung der Kanäle über das Bedienfeld

Hier kann eingestellt werden, ob eine Steuerung der LED Kanäle über das Bedienfeld erlaubt ist.

Auf der Startseite kann über die Taste [ ⬤ ] in den Kanalmodus geschaltet werden. über die Taste [ ◀ ] und [ ▶ ] können die Kanäle durchgeschaltet werden. Mit der Taste [ ⬤ ] kann der jeweils ausgewählte Kanal aktiviert bzw. deaktiviert werden. Mit der Taste [ ■ ] wird der Kanalmodus verlassen.
